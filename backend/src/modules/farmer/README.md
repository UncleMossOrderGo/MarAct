# สวนและ LINE OA

ผู้ขายเปิด `/market/farm` บนเครื่องเดโม จัดการสวน → สร้างรหัสเชื่อม LINE แล้วส่งข้อความที่ระบบแสดงเข้าแชตส่วนตัวกับ OA ผู้ขายเริ่มใน LINE ได้ด้วยข้อความ `เปิดสวน ชื่อสวน` และขอรหัสเข้าเว็บด้วย `เชื่อมเว็บ`

1. ส่งชื่อผลไม้ น้ำหนักรวม ราคาต่อหน่วย น้ำหนักต่อหน่วย ขั้นต่ำ วันพร้อมส่ง และพื้นที่ส่ง ส่งภาพสินค้าได้ ผู้ช่วยใช้ OpenAI สรุปเป็นร่าง
2. ส่ง `สรุปร่าง` และกดปุ่มยืนยันล่าสุด จึงเผยแพร่ล็อต ตัวอย่างในเครื่องใช้พื้นที่ `กรุงเทพฯ` เมื่อผู้ดูแลตั้งกฎสำหรับพื้นที่นี้
3. ผู้ซื้อค้นหาที่ `/market` ด้วยชื่อผลไม้ ระบุกิโลกรัม รหัสไปรษณีย์ และวันรับ ตรวจราคาและยืนยันการจอง
4. ผู้ขายส่ง `ออเดอร์` ใน LINE เพื่อดูการจองล่าสุด 5 รายการ หรือเปิดกล่องการจองในหน้าสวน ตอบ `รับออเดอร์ <UUID> <วิธีชำระเงิน>` หรือ `ปฏิเสธออเดอร์ <UUID> <เหตุผล>` ผู้ซื้อเห็นสถานะเมื่อโหลดคำสั่งซื้ออีกครั้ง

ผู้ขายส่ง `สต็อก` เพื่อดูลำดับล็อต ส่ง `ของหมด 1` หรือ `สต็อก 1 20` (น้ำหนักรวม 20 กก.) แล้วกดปุ่มยืนยัน การค้นหาและการเสนอราคาครั้งถัดไปจะตรวจจำนวนใหม่

## การเชื่อมต่อ

เซิร์ฟเวอร์อ่าน `LINE_CHANNEL_SECRET`, `LINE_CHANNEL_ACCESS_TOKEN`, `OPENAI_API_KEY`, `OPENAI_MODEL` ผู้ดูแล OA ชี้ webhook HTTPS เข้า `/api/farmer/line/webhook` หรือลิงก์เดิม `/api/ideas/idea-d/line/webhook` ตัวรับตรวจลายเซ็นและบันทึกเหตุการณ์ลงคิวก่อนตอบ การส่งข้อความซ้ำจาก LINE ใช้รหัสเหตุการณ์เดิม การทดสอบใช้ webhook ที่เซ็นด้วยรหัสทดสอบและแทนที่การส่งข้อความออก

ร่าง การผูกบัญชี คิว และภาพอยู่ในโฟลเดอร์ถาวรของ worker เดียว เลือกพาธด้วย `MARACT_FARM_DATA_DIR` (รองรับ `IDEA_D_DATA_DIR` เดิม) ล็อตที่ยืนยันแล้วและมีเงื่อนไขการส่งครบจะแสดงใน PostgreSQL ก่อนอ่านตลาดหรือเสนอราคา การจองจากผู้ซื้อทั้งตลาดและผู้ช่วยจัดซื้อจึงใช้ยอดเดียวกัน ระบุสต็อกเป็นน้ำหนักรวมของล็อต การแก้ราคาจะรักษายอดที่จองไปแล้ว

ตั้ง `MARACT_FARM_DELIVERY` เป็น JSON ที่ระบุกติกาตามชื่อพื้นที่ส่งที่ตกลงกัน ตัวอย่างสำหรับเดโม:

```json
{"กรุงเทพฯ":{"postcodes":["10"],"transit":1,"freight":60,"window_days":7}}
```

ตัวอย่างนี้กำหนดค่าขนส่ง 60 บาท ระยะขนส่ง 1 วัน เปิดส่ง 7 วันนับจากวันพร้อมส่ง และรับปลายทางรหัสไปรษณีย์ขึ้นต้นด้วย 10 พื้นที่ที่ไม่ตรงกับกฎยังแสดงในหน้าสวน ผู้ซื้อจองได้เมื่อข้อมูลครบและตลาดรองรับหน่วยกับราคาแล้ว ตลาดคิดราคาเป็นเงินบาทเต็มต่อหน่วย การรับจองบันทึกวิธีชำระเงินที่สวนระบุ
