# Farmer Studio · Farmer Profile และผู้ช่วยลงขาย

## เปิดจากเครื่องที่รัน MarAct

จาก root โปรเจกต์ ใช้ Python environment และ npm package ของโปรเจกต์ร่วมกัน

```powershell
npm.cmd --prefix frontend run build
uv run --locked python -m backend.src.app.server --port 3000
```

เปิด [หลังร้าน](http://127.0.0.1:3000/farmer) หรือ [ตลาดผลไม้](http://127.0.0.1:3000/farms) ได้จากเบราว์เซอร์เดียวกัน หากใช้ Vite ที่พอร์ต 5173 ให้ใช้เส้นทางเดียวกัน เว็บจะส่งคำขอ API ต่อไปที่ backend

## การลงขาย

- **เริ่มจากเว็บ** เปิดจัดการสวนเพื่อแก้ชื่อ ที่ตั้ง และพื้นที่ส่ง จากนั้นเปิดผู้ช่วยลงขาย พิมพ์รายละเอียดหรือกรอกเอง เพิ่มรูปได้สูงสุด 6 รูป เลือกรูปปก ตรวจร่าง แล้วกดยืนยัน
- **ผูกสวนบนเว็บกับ LINE** เปิดจัดการสวน → สร้างรหัสเชื่อม LINE แล้วส่งข้อความที่แสดงในแชตส่วนตัวกับ OA รหัสใช้ครั้งเดียวภายใน 10 นาที เมื่อเชื่อมแล้ว ทั้งสองช่องทางใช้ร่างเดียวกัน
- **เริ่มจาก LINE** ส่ง `เปิดสวน ชื่อสวนของคุณ` ตามด้วยรายละเอียดและรูป เมื่ออยากจัดการบนเว็บให้พิมพ์ `เชื่อมเว็บ` แล้วกรอกรหัสที่จัดการสวน → เปิดสวนที่สร้างใน LINE
- **ตรวจร่าง** พิมพ์ `สรุปร่าง` ใน LINE ได้ทุกเมื่อ หากข้อมูลขาด ผู้ช่วยจะถามกลับ เมื่อครบจึงแสดงปุ่มยืนยัน หากมีการแก้ไขระหว่างนั้นต้องตรวจสรุปล่าสุด บนเว็บใช้ปุ่มโหลดร่างล่าสุดหรือรีเฟรชหน้า
- **หลังยืนยัน** ประกาศจะขึ้นทั้งหน้าสวนและตลาด ผู้ซื้อค้นหาจากชื่อผลไม้ สวน หรือพื้นที่ส่งได้ การเปลี่ยนราคาและสต็อกในหลังร้านใช้กับประกาศที่ผู้ซื้อเห็นด้วย

เข้าสู่ระบบที่ `/login` ด้วยชื่อบัญชีและรหัสผ่าน หรือเลือกใช้รหัสจากคำสั่ง “เชื่อมเว็บ” ใน LINE บัญชีที่สมัครใหม่ได้สวนใหม่ของตนเอง ผู้ซื้อดูประกาศที่ยืนยันแล้วได้ที่ `/farms`

เครื่องต้นแบบเก็บสิทธิ์เจ้าของสวนในคุกกี้ของเบราว์เซอร์บน localhost สวนเดโมเริ่มต้นมีมะม่วงสองล็อต เบราว์เซอร์ใหม่ต้องเข้าสู่ระบบก่อนเปิดหลังร้าน เจ้าของที่เชื่อม LINE ไว้ขอรหัสเปิดสวนเดิมได้จากแชต ระบบเก็บข้อมูลและรูปใน `backend/.local/farmer/` หรือโฟลเดอร์ที่กำหนดด้วย `FARMER_DATA_DIR`

## LINE และโมเดล

backend อ่าน `LINE_CHANNEL_SECRET`, `LINE_CHANNEL_ACCESS_TOKEN`, `OPENAI_API_KEY` และ `OPENAI_MODEL` จาก environment หรือไฟล์ `.env` ที่ root โมเดลเริ่มต้นคือ `gpt-6.1-terra`

เส้นทางรับเหตุการณ์คือ `POST /api/ideas/idea-d/line/webhook` การใช้งานจากแอป LINE จริงต้องให้เซิร์ฟเวอร์ LINE เข้าถึงเส้นทางนี้ผ่าน HTTPS และเปิด Use webhook ของ OA ส่วนการทดสอบในเครื่องใช้เหตุการณ์ที่เซ็นลายเซ็นทดสอบ ส่งเข้าแอปได้โดยตรง ดู [การรับ webhook ของ LINE](https://developers.line.biz/en/docs/messaging-api/receiving-messages/)

## ทดสอบโมดูล Farmer

```powershell
uv run --locked python -m pytest backend/tests/farmer -q
npm.cmd --prefix frontend run test:web -- farmer-
```

ชุดทดสอบจำลอง LLM และ LINE ทั้งการส่งข้อความตอบกลับและการดาวน์โหลดรูป พร้อมฐาน SQLite แยกจากข้อมูลสวนจริง Playwright เปิดเซิร์ฟเวอร์ทดสอบบน loopback ตรวจการลงขายจากเว็บ และเปิดประกาศในเบราว์เซอร์ผู้ซื้ออีกบัญชี

หน้าเว็บอยู่ใน `frontend/src/features/farmer/` ส่วน backend อยู่ใน `backend/src/modules/farmer/` ไฟล์ `router.py` ดูแลสวนและร่าง, `seller_agent.py` เรียกโมเดล, `line.py` รับเหตุการณ์ LINE และผูกบัญชี, `listings.py` ให้ผู้ซื้ออ่านประกาศและรูปที่เผยแพร่แล้ว
