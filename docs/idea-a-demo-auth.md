# Idea A demo sign-in

The backend reads one shared demo buyer account from its environment. Set these values in the backend `.env` and restart the API.

- `IDEA_A_DEMO_EMAIL` is the email buyers enter on the sign-in screen.
- `IDEA_A_DEMO_PASSWORD_HASH` is the full string printed by this command. Enter the password at the prompt.

  ```sh
  uv run --locked python -c 'from getpass import getpass; from backend.src.modules.idea_a.marketplace.auth import make_password_hash; print(make_password_hash(getpass("Demo password: ")))'
  ```

- `IDEA_A_SESSION_SECRET` is a randomly generated secret. Generate a separate value for each environment.

  ```sh
  uv run --locked python -c 'import secrets; print(secrets.token_urlsafe(32))'
  ```

Keep these settings in the backend environment and pass the plaintext password separately to demo buyers. A deployed HTTPS reverse proxy should forward the original host and protocol to the API so cookies are marked Secure and browser origins match.

CI can construct `DemoAuth.from_env(settings)` with a test-only address, a hash generated by `make_password_hash(test_password)`, and a fresh secret from `secrets.token_urlsafe(32)`. The focused tests generate their own credentials.

```sh
uv run --locked pytest -q backend/src/modules/idea_a/marketplace/test_auth.py
```
