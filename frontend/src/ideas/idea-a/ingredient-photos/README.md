# Demo ingredient imagery

The existing mascot and fruit photos remain the approved reusable MarAct assets. This folder supplies square synthetic demo imagery generated for MarAct. The photos depict example ingredients, not actual inventory or supplier-uploaded evidence.

| Keys | Source |
| --- | --- |
| pistachio-gelato, pistachio-paste, whipping-cream, milk, strawberry-shortcake, mango-smoothie | Generated six-photo supplier-style contact sheet, exported as individual WebP files |
| blueberry, cream-cheese, butter, unsalted-butter, chocolate-chips | Generated four-photo bakery catalog contact sheet |
| flour through almond, oat, honey, coffee, black-tea | Generated pantry and produce contact sheets, exported as individual WebP files |
| fallback | Local neutral placeholder for unknown or missing keys |

Resolve images through `ingredientImage(key)`. Keep the same key when replacing a demo image with an authorized supplier photo.
